# Ripple

When something goes wrong in the AI hardware supply chain, who gets hit, and why?

Ripple maps who supplies whom across memory, chip packaging, power equipment and raw materials, using
public filings, and traces each new event out to the companies it reaches. Every link points to the
sentence in the filing it came from.
